# DAR-LTCMS

**Department of Agrarian Reform – Land Transfer Clearance and Monitoring System**

DAR-LTCMS supports land transfer clearance processing, records management, document review, clearance generation, and monitoring for the DAR Negros Oriental Provincial Office.

Legal Clearance Staff encode applications and record office actions. Landowners can view their linked records, while Geodetic personnel have authorized parcel and map access.

**Approved** is the current final application decision. Compliance requests handle issues that need correction, and release tracking records delivery of the clearance separately. These actions do not transfer legal land ownership or alter registry records.

The system uses Laravel 12, PHP 8.4, PostgreSQL 18, Blade, Tailwind CSS, Vite, and Leaflet.
